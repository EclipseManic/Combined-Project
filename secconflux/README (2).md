# 🛡️ SecConflux 2.0 — Unified SecOps Platform

**Converge. Correlate. Contain.**

Unified React 19 + TypeScript 5.7 + Tailwind v4 analyst platform consolidating 5 security engines:
1. **🔬 Malware Analyzer** (`#/t/malware` & `#/t/malware/investigation`)
2. **🔍 IOC Lookup Platform** (`#/t/ioc` & `#/t/ioc/lookup`)
3. **📋 Event Analyzer** (`#/t/events` & `#/t/events/investigation`)
4. **🎣 Phishing Mail Detector** (`#/t/phishing` & `#/t/phishing/analysis` — sub-tab `dashboard` bug fixed)
5. **⚒️ RuleForge** (`#/t/ruleforge` & `#/t/ruleforge/workshop` — main-tab `workshop` bug fixed)

## Quick Start
```bash
npm install
npm run dev
```
